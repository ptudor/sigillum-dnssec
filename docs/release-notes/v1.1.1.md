Sigillum 1.1.1 is 1.1.0 with signed packages. Both executables are unchanged;
see the [1.1.0 notes](https://github.com/ptudor/sigillum-dnssec/blob/v1.1.1/docs/release-notes/v1.1.0.md)
for features and upgrade guidance.

### Signed packages and manifest

- RPMs, DEBs, and `checksums.txt` are signed with the project's OpenPGP release
  key, fingerprint `8C4F 58EF B945 4902 267D  9B3E 426C 4AA2 1A40 0728`. The
  public key is
  [`packaging/release-signing-key.asc`](https://github.com/ptudor/sigillum-dnssec/blob/v1.1.1/packaging/release-signing-key.asc)
  in the repository. The same key signs Carillon releases.
- After `sudo rpm --import release-signing-key.asc`, `rpm -K` reports
  `digests signatures OK` and DNF installs the packages with
  `--setopt=localpkg_gpgcheck=1`; the earlier `localpkg_gpgcheck=0` is no longer needed.
- APT and dpkg do not check a local DEB's embedded signature. For DEBs and
  archives, verify `checksums.txt.sig` with `gpg --verify`, then the hashes.
- The release workflow refuses to build unless its signing secret matches the
  published key. Before attestation and publication it verifies every signature
  against that key, including Debian and Fedora installations with DNF signature
  checking enforced.

Releases through 1.1.0 remain unsigned; their checksums and build attestations
are unchanged.

### Downloads and verification

Each archive contains both executables. Separate signer and validator packages
are available for Linux.

| Platform | Architectures | Files |
| --- | --- | --- |
| Linux | amd64, arm64 | `.tar.gz`, signed `.rpm`, signed `.deb` |
| FreeBSD | amd64, arm64 | `.tar.gz` with rc.d examples |
| macOS | amd64, arm64 | `.tar.gz` for local tools and development |

Verify the signature on `checksums.txt`, the SHA-256 hashes, and the GitHub build
attestation before installation. Release checks are those of 1.1.0, with
signature verification added: native race tests on Linux amd64, Linux arm64, and
macOS arm64; BIND RSA import and rollover interoperability; all release
cross-builds; Debian and Fedora package lifecycle tests; vulnerability scans; and
a full-history secret scan. FreeBSD artifacts are cross-built, without native
FreeBSD runtime tests in CI.
