**Draft release notes — version 1.0.0 is unpublished.**

Sigillum 1.0 brings together two tools for operators of their own nameservers:

- **dnssec-tudor** watches and signs zone files, refreshes signatures, manages key
  rollovers, and exposes status and registrar DS records.
- **dnssec-validator** walks delegations, verifies signatures and authenticated
  denial, and streams its findings to an embedded browser interface.

Both programs run independently. The signer works beside NSD or BIND; the
validator can inspect zones signed by other implementations.

### Downloads

Choose the archive matching your OS and architecture. Every archive contains
both executables. Linux packages are separate, so you can install either tool.

| Platform | Architectures | Files |
| --- | --- | --- |
| Linux | amd64, arm64 | `.tar.gz`, `.rpm`, `.deb` |
| FreeBSD | amd64, arm64 | `.tar.gz` with rc.d examples |
| macOS | amd64, arm64 | `.tar.gz` for local tools and development |

RPMs and DEBs are unsigned. Packages preserve configuration and do not enable or
start services. Check the SHA-256 manifest and GitHub build attestation before
installation, then follow the [Linux setup guide](https://github.com/ptudor/sigillum-dnssec/blob/main/docs/linux-packages.md).

### Verification and licensing

Native race tests cover Linux amd64, Linux arm64, and macOS arm64. CI cross-builds
every release target, exercises package installation/reinstallation/removal in
Debian 13 and Fedora 43, and runs vulnerability and full-history secret scans.
FreeBSD builds are cross-compiled; they are not native FreeBSD runtime tests.

The project is MIT-licensed. Archives and packages preserve the licenses and
attribution notices of their compiled dependencies.
